# CO2 Cooler Atlas — published viewer

This repository contains the validated compiled viewer and eleven derived model
packets approved for public distribution by the project owner on 2026-10-05.
It does not contain the original manufacturer CAD, private drawings, workbooks,
credentials or the history of the private application repository.

Application code is covered by its included license. Manufacturer-derived
geometry is not relicensed under MIT; see ATTRIBUTION.md and THIRD_PARTY_NOTICES.md.

This initial snapshot is published separately. An automated connection from the
private application's main branch is not yet active. GitHub Pages publishes this
repository's main branch after it is updated.
