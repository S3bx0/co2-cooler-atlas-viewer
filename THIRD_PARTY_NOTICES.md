Some dependencies contain helpers not exercised by this viewer. Redistributions of the built website should include this file and the accompanying `licenses/` directory. Review the inventory when imports or dependency versions change.

`three-mesh-bvh` **0.8.3** for development-only generated-fin picking and geometry
tests. No package version was upgraded. Its MIT notice is preserved verbatim
from the installed package in [three-mesh-bvh-MIT.txt](licenses/three-mesh-bvh-MIT.txt).

included in the production review-free viewer.
